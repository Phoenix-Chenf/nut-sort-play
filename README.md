# 理一理 · 螺母整理

手机和电脑都能玩的网页小游戏。经典整理、迷雾整理、顺序收集各 100 关，共 300 关。

[打开试玩](https://phoenix-chenf.github.io/nut-sort-play/)

- **经典整理**：把同色螺母装满一根柱子。
- **迷雾整理**：移开顶上的螺母，露出下面的颜色；见过的颜色会记住。
- **顺序收集**：按目标顺序整理满柱，收走后腾出中转空间。

非空柱只能放顶部同色的螺母，空柱可放任意颜色。不限尝试次数，可随时撤回、免费加空柱，也可以查看下一步提示。通关后显示用时、步数、加柱情况及本关最好成绩，未加柱和加柱辅助分别记录。后台、玩法说明和选关时暂停计时。

进度、撤回历史和成绩保存在当前浏览器，不跨设备或站点同步；清理浏览器数据会清除记录。没有广告、付费或登录要求。

支持链接参数：`?mode=classic`、`?mode=fog`、`?mode=collect`；可加 `&level=100` 直接挑战对应关卡。前 30 关保持原样，后续增加颜色交错与层数。每关经过引擎验证可解；体感难度以试玩为准。

本仓库包含网页运行文件。可下载后运行 `python3 -m http.server 8771`，在浏览器打开 http://127.0.0.1:8771/ 。
